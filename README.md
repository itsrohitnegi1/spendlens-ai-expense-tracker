# SpendLens — AI Expense Tracker

SpendLens is an AI-powered expense tracker that helps users understand and manage their spending with intelligent insights.

## 🚀 What it does
- Track and organize expenses  
- Categorize transactions intelligently  
- Generate insights to understand spending behavior  

## 🧠 Why it’s different
Instead of just logging expenses, SpendLens focuses on **understanding spending patterns and making them actionable**.

## 🛠 Tech Stack
- **Frontend:** React + Vite  
- **State Management:** React Hooks  
- **Styling:** CSS / Tailwind 
- **AI Integration:** OpenAI API (for smart insights / categorization)  
- **Build Tool:** Vite
